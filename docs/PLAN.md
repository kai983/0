## 1. 제품 정의

공유 한 번으로 지식이 AI 요약과 함께 쌓이고, 학습 카드로 되살아나는 개인 지식 앱.
유튜브 - 기사 - 리포트 - 글을 공유하면 앱이 알아서 저장하고, Gemini 무료 API가
요약 - 인사이트 - 태그를 붙이며, 간격 반복 학습으로 기억까지 책임진다. 추가 비용은 0원.

## 2. 의도 분해

- 수집은 마찰 0 - "공유하면 아무런 클릭 없이 자동으로 내가 원하는 형태로 가공해서 저장"
- 재가공은 AI가, 비용은 0원 - "돈은 정액제 외에 추가로는 안 나가고 싶고"
- 회수는 편안하게 - 검색, 태그, 훑기 좋은 목록, 테마. UI는 실제 레퍼런스 기반, AI 티 금지
- 기억은 학습으로 - 간격 반복으로 다시 꺼내 준다
- 운영 원칙 - 버전 표기(+0.01 작은 변경, +0.1 큰 변경), 하이픈(-)만 사용, 캔버스는 앱과 동기화

## 6. 지키는 원칙

- 추가 비용 0원 - 무료 티어 안에서만, 한도 초과 시 과금 대신 대기 안내
- API 키는 기기에만 저장, 어디에도 전송하지 않음
- 로그인된 웹 AI 자동 조작은 약관 위반 - 계정 정지 위험이라 만들지 않음. 무료 API가 공식 통로
- 캡처는 절대 유실하지 않음 - AI 실패해도 원본은 저장된 상태로 남음
- 하이픈 통일, 버전 표기, 캔버스 동기화 유지

## 7. 검증 계획 - 실기기 체크리스트

1. 설정(팔레트 버튼)에서 "무료 키 만들기" 링크로 키 발급 후 붙여넣고 저장
2. 유튜브 영상 공유 - 클릭 없이 요약 - 태그가 붙는지
3. 기사 URL 공유로 같은 확인
4. 상세 화면에서 학습 카드 "자동 생성" - 학습 탭에서 문답 진행
5. 키를 지운 상태에서 공유 - 기존 수동 선택 화면이 뜨는지
